# TurboBoost Ultra

Переписанный клиентский оптимизатор для **Minecraft 1.21.1 + NeoForge 21.1.x**. Нужна **Java 21**.

## Скачать готовый JAR

**[Скачать TurboBoost Ultra 2.0.0](https://github.com/zxcwmd/turbo/releases/download/turboboost-neoforge-1.21.1-v2.0.0/turboboost-neoforge-1.21.1-2.0.0.jar)** · [Страница релиза](https://github.com/zxcwmd/turbo/releases/tag/turboboost-neoforge-1.21.1-v2.0.0)

Установка: помести JAR в `mods` профиля NeoForge 1.21.1. Мод работает только на клиенте, на сервер ставить не нужно.

## Что делает мод

### Адаптивный «турбо»-профиль

Раз в несколько секунд сравнивает FPS с заданной целью. При устойчивой просадке последовательно снижает дальность прорисовки и цену нескольких видеонастроек: частицы, облака, ambient occlusion, дальность отображения сущностей, смешивание цветов биомов и тени сущностей. После стабилизации FPS постепенно возвращает настройки игрока.

Клавиша **P** вручную включает/выключает профиль. Настройки можно изменить в `config/turboboost-client.toml`.

### Occlusion culling живых сущностей

В дополнение к настройкам мод проверяет лучами видимость ближайших мобов, кэширует результат и пропускает рендер сущности, только когда несколько точек её модели закрыты блоками, которые полностью заслоняют обзор. Чтобы не тратить кадр на проверки, есть лимит проверок на тик. Игроки, подсвеченные, горящие, невидимые и поименованные сущности не скрываются.

Это клиентская оптимизация отрисовки: поведение мобов и серверная симуляция не меняются.

### Дополнительный режим для одиночной игры

Опциональная настройка `lowerSimulationDistanceWhenFpsIsLow` снижает дистанцию симуляции интегрированного сервера при просадке FPS. **По умолчанию выключена:** меньшая дистанция симуляции меняет область тиков блоков и мобов, поэтому может повлиять на фермы и игровой процесс. В мультиплеере эта функция не применяется.

## Максимум производительности

На NeoForge 1.21.1 наиболее тяжёлую работу по ускорению рендера обычно делают специализированные рендереры. [Embeddium 1.0.15 для NeoForge 1.21.1](https://www.curseforge.com/minecraft/mc-mods/embeddium/files/6118392) использует оптимизированный рендер-пайплайн; [ImmediatelyFast](https://modrinth.com/mod/immediatelyfast) ускоряет immediate-mode отрисовку, а [ModernFix](https://modrinth.com/mod/modernfix?version=1.21.1) и [FerriteCore](https://modrinth.com/mod/ferrite-core?version=1.21.1) помогают со временем загрузки, памятью и GC-паузами. Эти моды устанавливаются **отдельно** и не включены в этот JAR. Не ставь одновременно несколько заменяющих рендерер модов; проверь совместимость с Oculus, шейдерами и модпаком.

TurboBoost не обещает фиксированное число FPS: выигрыш зависит от того, упирается ли конкретная сборка в GPU, CPU, память или серверный TPS. Проверь свой набор модов и настройки по одному.

## Сборка исходников

Требуется Java 21. В проект положен Gradle Wrapper:

```bash
./gradlew --no-daemon clean build
```

JAR создаётся в `build/libs/`.

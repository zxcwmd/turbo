# TurboBoost

Адаптивный клиентский оптимизатор для **Minecraft 1.20.1 + Forge 47.3.0+**. Работает без доступа к миру и не меняет игровые механики.

## Что делает

- Следит за FPS и снижает дальность прорисовки, если производительность стабильно ниже заданного порога.
- По мере восстановления FPS постепенно возвращает дальность прорисовки к настройке, которая была выбрана игроком.
- При длительной просадке временно переключает частицы на минимальные и отключает тени сущностей; после стабилизации возвращает прежние значения.
- Все изменения происходят только на клиенте и восстанавливаются при выходе с сервера/из мира или при отключении мода в конфиге.
- Не требует установки на сервере и не меняет игровые файлы.

Это не магический «удвоитель FPS»: реальный эффект зависит от железа, сборки и причины просадок. Мод автоматически управляет только обычными видеонастройками Minecraft; никаких обещаний обхода ограничений или ускорения сетевого соединения.

## Установка

1. Установи Java 17 и Forge для Minecraft 1.20.1.
2. Скачай `turboboost-1.0.0.jar` из [GitHub Releases](https://github.com/zxcwmd/turbo/releases) или артефакт последней сборки GitHub Actions.
3. Положи JAR в папку `mods` и запусти игру с Forge 1.20.1.
4. Параметры после первого запуска появятся в `config/turboboost-client.toml`.

Мод клиентский: на сервер его ставить не нужно.

## Сборка из исходников

Нужны Java 17 и Gradle 8.8:

```bash
gradle --no-daemon clean build
```

Готовый JAR появится в `build/libs/`.

## Настройки

- `enabled` — включить/выключить адаптивное управление.
- `targetFps`, `fpsMargin` — целевой FPS и зона гистерезиса.
- `minimumRenderDistance` — нижняя граница дальности прорисовки.
- `sampleIntervalTicks`, `recoverySamples`, `recoveryStepTicks` — частота замеров и скорость восстановления.
- `reduceParticles`, `disableEntityShadows` — включить или отключить дополнительные меры.

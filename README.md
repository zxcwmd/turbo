# TurboBoost

Адаптивный клиентский оптимизатор для **Minecraft 1.20.1 + Forge 47.3.0+**. Работает без доступа к миру и не меняет игровые механики.

## Что делает

- Следит за FPS и снижает дальность прорисовки, если производительность стабильно ниже заданного порога.
- По мере восстановления FPS постепенно возвращает дальность прорисовки к настройке, которая была выбрана игроком.
- При длительной просадке автоматически снижает дальность прорисовки **и дальность отображения сущностей**.
- В адаптивном режиме может временно отключить облака и ambient occlusion, уменьшить смешивание цветов биомов, поставить частицы на минимум и отключить тени сущностей.
- Когда FPS стабилизируется, возвращает прежние настройки и поэтапно восстанавливает дальность прорисовки.
- Все изменения происходят только на клиенте и восстанавливаются при выходе из мира или отключении мода в конфиге.
- Не требует установки на сервере и не меняет игровые механики.

Это не магический «удвоитель FPS»: реальный эффект зависит от железа, сборки и причины просадок. Для особенно большого прироста важен источник bottleneck: TurboBoost адаптирует стандартные настройки, а замена рендерера и специализированные оптимизаторы затрагивают более глубокие участки игры.

## Что ещё поставить для заметного прироста

Для Forge 1.20.1 полезно рассмотреть проверенные отдельные моды (скачивай именно файлы для **Forge 1.20.1**):

- [Embeddium](https://www.curseforge.com/minecraft/mc-mods/embeddium) — рендерер на базе Sodium; переписывает отрисовку чанков и другие клиентские пути. Обычно это самый сильный дополнительный шаг для GPU/рендерного bottleneck. Не ставь одновременно с OptiFine или другим заменяющим рендерер модом.
- [Entity Culling](https://www.curseforge.com/minecraft/mc-mods/entityculling) — пропускает отрисовку скрытых за стенами сущностей и block entities; особенно полезен на базах и фермах. Реальный выигрыш зависит от сцены и железа.
- [ImmediatelyFast](https://modrinth.com/mod/immediatelyfast) — оптимизирует immediate-mode отрисовку GUI, текста, карт, частиц и сущностей; у проекта есть сборка для Forge 1.20.1.
- [ModernFix](https://modrinth.com/mod/modernfix) и [FerriteCore](https://modrinth.com/mod/ferrite-core) — в первую очередь уменьшают расход памяти, ускоряют загрузку и помогают большим модпакам со stutter/GC; сами по себе не обещают огромный прирост среднего FPS.

Это отдельные проекты, не встроенные в TurboBoost. Ставь их по одному, делай копию мира и проверяй совместимость с конкретной сборкой. Если игра упирается в серверный TPS, сеть или CPU-логику модпака, клиентские графические оптимизации этого не исправят.

## Установка

1. Установи Java 17 и Forge для Minecraft 1.20.1.
2. Скачай `turboboost-1.1.0.jar` из [GitHub Releases](https://github.com/zxcwmd/turbo/releases) или артефакт последней сборки GitHub Actions.
3. Положи JAR в папку `mods` и запусти игру с Forge 1.20.1.
4. Параметры после первого запуска появятся в `config/turboboost-client.toml`.

Мод клиентский: на сервер его ставить не нужно.

## Сборка из исходников

Нужны Java 17 и Gradle 8.8:

```bash
gradle --no-daemon clean build
```

Готовый JAR появится в `build/libs/`.

## Настройки

- `enabled` — включить/выключить адаптивное управление.
- `targetFps`, `fpsMargin` — целевой FPS и зона гистерезиса.
- `minimumRenderDistance` — нижняя граница дальности прорисовки.
- `sampleIntervalTicks`, `recoverySamples`, `recoveryStepTicks` — частота замеров и скорость восстановления.
- `reduceParticles`, `disableEntityShadows`, `disableClouds`, `disableAmbientOcclusion`, `reduceEntityDistance`, `reduceBiomeBlend` — включить/отключить отдельные адаптивные меры.
